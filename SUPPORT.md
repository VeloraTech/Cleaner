# Support

## Questions

For general questions about Cleaner, use GitHub Discussions if enabled.

Good questions include:

- How does a feature work?
- Why was an implementation chosen?
- How should I approach contributing?
- Can Cleaner support a particular use case?

## Bugs

If you believe you found a bug, open a GitHub issue using the bug-report template.

Please include:

- what you expected
- what happened
- reproduction steps
- relevant source-code example
- environment information
- screenshots/logs when useful

## Feature Ideas

Feature requests are welcome.

Before proposing a large feature, explain the problem first.

A useful feature request answers:

```text
What problem exists?
Who experiences it?
What would a good solution look like?
What alternatives were considered?
```

## Security

Do not report security vulnerabilities publicly.

See `SECURITY.md`.
